# Relay (데모)

회사의 모든 외부·내부 소통을 스페이스 단위로 모아 **회사 자산**으로 만드는 서비스의 데모 화면입니다.
기능 연결 없이 화면과 흐름만 있습니다. 데이터는 `src/lib/mock-data.ts`의 가상 데이터이고, 새로고침하면 처음 상태로 돌아갑니다.

## 실행

```bash
pnpm install
pnpm dev
```

http://localhost:3100 에서 열립니다.

## 화면과 기능 매핑

화면마다 버튼별 사용법과 데모 동작은 **`화면별_기능정리.md`**에 정리했습니다. 앱 안에서는 상단 **화면 안내(?)**로 볼 수 있습니다.
기능 번호는 회의록 기반 `릴레이_기능정리.md`의 ID입니다.

| 화면 | 경로 | 보여주는 기능 |
|---|---|---|
| 오늘 할 일 | `/today` | 나에게 걸린 일 모아 보기: 답장할 대화, 7일 안 마감, 고객에게 한 약속, 미팅, 보낼 만한 안내 (2-1, 1-9) |
| 통합 수신함 | `/inbox` | 채널 통합 수신(1-1~1-3), 단체 대화, 메시지마다 쌓을 스페이스(여러 곳 가능)·개인 대화 고르기, 안 읽은 내용 요약, 채팅방별 AI 답장 켜기·끄기, 답장 필요 건(2-1), AI 초안·승인 후 발송(2-2, 2-5), 초안 근거 문서 링크(5-1), 채널별 발송 방식(2-4), 수정 내역 학습(2-6), 미팅 일정 등록(2-3), 유사 건 추천(4-1, 4-2) |
| 스페이스 목록 | `/spaces` | 전체 / 내 스페이스, 검색, 먼데이 칼럼(진행 단계·진행률·다음 마감)과 칼럼 설정, 스페이스별 상태·고객사·참여자 수·문서·핵심 정보(3-2), 새 스페이스 **안 A**(1-8) |
| 스페이스 상세 | `/spaces/[id]` | 제목 아래 먼데이 요약, 회의 탭(요약·할 일·후속 메일), 견적서·계약서 초안(2-7), 개요(AI 요약·먼데이 업무 현황·지금 할 일·핵심 정보와 출처·최근 문서), 먼데이 업무 탭(칼럼 설정·관련 대화), 참여자 추가·빼기·교체(3-3), 채팅방 연결·끊기(한 채팅방을 여러 스페이스에, n:m), 스페이스 문서(메일·메신저 첨부 자동 저장 포함), 이 스페이스로 쌓인 소통 내역, 회사 기준(5-1~5-3), 열람 권한(6-2) |
| 고객사 목록 | `/clients` | 거래 중인 고객사 목록과 검색(3-1), 상황(공지·정기 일정·계약 갱신)별로 여러 고객사에 맞춤 메일 한 번에 보내기 |
| 고객사 상세 | `/clients/[id]` | 그 회사와 진행한 스페이스, 연락처(3-1, 3-2), 그 회사 모든 스페이스에 참고하는 공통 자료 |
| 지식 베이스 | `/knowledge` | 우리 회사 → 고객사 → 스페이스 트리로 정리한 자료·대화·핵심 정보·해결된 사례, 고객사 공통 자료, AI가 자료를 쓰는 법(회사 기준은 늘 지키는 규칙, 나머지는 가까운 자료 우선: 스페이스 → 고객사 공통 → 회사 자료, 5-3·5-5), 확인이 필요한 자료와 최신화 요청(5-6), 회사 기준 켜기·끄기(팀장), 대화 검색 기간(5-4), 자료 올리기(5-2, 6-4) |
| 채널 연동 | `/channels` | 권한 키 연동(1-4), 채널마다 계정 여러 개 연결·팀 공용 계정, 채널별 범위(1-5, 1-6), 대화 파일 업로드(1-7), 채널 연동 시 스페이스 지정 **안 B**(1-8) |
| 설정 | `/settings` | 내 설정(알림·서명·AI 기본값), 팀 설정(팀원·권한 6-2, AI 기준, 먼데이 연동, 보안·활동 기록 6-1·6-3·6-4, 요금·크레딧 BM, 답장 학습 2-6) |

상단의 **담당자로 보기 / 팀장으로 보기** 전환으로 열람 권한 차이(개인 연락 노출 여부)를 확인할 수 있습니다.

모든 화면에서 `Ctrl+K`(또는 `/`)로 스페이스·고객사·대화·문서를 검색할 수 있습니다. 왼쪽 위 Relay 옆 버튼으로 메뉴를 접을 수 있습니다.

## 디자인 바꾸기

- 브랜드 색: `src/app/globals.css`의 `--color-brand-*`에서 `indigo`를 다른 Tailwind 색 이름으로 바꾸면 전체에 반영됩니다.
- 버튼·배지·카드·창: `src/components/ui/`
- 화면 안내 문구: `src/lib/page-guides.ts`

## 구조

```
src/
  app/                  라우트 (페이지는 화면 컴포넌트만 렌더링)
  components/
    inbox/              통합 수신함, 대화, AI 초안, 유사 건 패널
    knowledge/          지식 베이스, 문서 올리기
    channels/           채널 연동(안 B), 카톡 대화 파일 올리기
    settings/           권한·보안·크레딧
    projects/           스페이스 목록·상세, 새 스페이스(안 A), 참여자 추가·교체
    clients/            고객사 목록·상세
    docs/               문서 표, 미리보기, 문서 올리기
    layout/             사이드바, 상단바, 검색 창, 화면 안내, 토스트
    today/              오늘 할 일
    ui/, common/        공용 컴포넌트
  lib/
    mock-data.ts        가상 데이터 (회사·사람 이름 모두 가상)
    demo-context.tsx    데모 상태 (발송, 담당자 변경, 채널 연결, 권한 전환)
    channels.ts         채널 정의와 발송 방식 (데모용 가정)
    page-guides.ts      화면 안내(?)에 나오는 화면별 기능 설명
    types.ts            타입
```

## 메모

- 먼데이 값(진행 단계·진행률·마감·하위 업무)은 `src/lib/mock-data.ts`의 `MONDAY_ITEMS` 가상 데이터입니다. 실제 연동 시 먼데이 API에서 받아와 같은 모양으로 채웁니다.
- 채널별 발송 방식(자동 발송 / 초안만)은 데모용 가정입니다. 실제 API 조사 결과에 맞춰 `src/lib/channels.ts`를 고칩니다.
- 데모를 다듬다가 결정을 미룬 것(동료끼리 1:1 채팅 노출 등)은 `화면별_기능정리.md`의 **논의할 것**에 모아 둡니다.
- 스페이스-채널 연결 방식은 회의에서 미결이라 **안 A**(새 스페이스 창)와 **안 B**(채널 연결 창)를 모두 넣었습니다.
- 스택: Next.js 16 (App Router), React 19, Tailwind CSS 4, TypeScript, lucide-react.
